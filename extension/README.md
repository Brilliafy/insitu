# InSitu: In-Editor Voice & Socratic AI Mentor

In-Window Topmost HUD Overlay with Low-Latency STT/TTS Voice Dictation, Visual In-Editor Navigation, and Dual-Channel AI Mentorship for VS Code and Google Antigravity.

## Features
- **In-Window Floating HUD & Palette (`Ctrl+Alt+T`)**: Minimalist, frameless HUD overlay for hands-free pair-programming.
- **Voice Dictation (`Ctrl+Alt+M`)**: Low-latency local transcription with coding vocabulary bias.
- **Dual-Channel Voice Mentorship**: Full technical explanations in chat + punchy, human spoken audio companions.
- **Hardware Acceleration (`Ctrl+Alt+G`)**: Instant one-click toggling between CPU INT8 and GPU CUDA FP16.
- **3 Pedagogical Mentorship Modes**:
  1. Section Scaffold (Feature flow)
  2. Line-by-Line Step (Pedagogical micro-steps)
  3. Refactor & Doubt (Interactive code inspection)
- **Disk Space Reclaim**: Inspect on-disk model cache sizes and purge weights with 1 click.
